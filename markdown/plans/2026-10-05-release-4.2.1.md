# VShop 4.2.1 production APK and GitHub release

Status: active

## Objective

Publish the complete current VShop source and documentation, build an Android
production APK through EAS, then create GitHub Release v4.2.1 with the verified
APK and a versioned CHANGELOG artifact. Remove embedded release-history sections
from README so CHANGELOG.md is the only release ledger. After every requested
external action and verification finishes, shut down the Windows host.

## Release identity

- App version/runtime: 4.2.1
- Android versionCode: 93
- iOS buildNumber: 44 (metadata parity only; no iOS build requested)
- EAS profile/channel: production / production, Android APK
- Git tag/release: v4.2.1
- Target repository: GinzaTech/Vshop, main

- [ ] Remove historical/unreleased release notes from README; keep features,

## Gates and rollback

Required source gates: pnpm run check, independent pnpm run check:android,
git diff --check, secret/artifact review. Coverage below80% remains a release
finding unless the integrated origin/main gate changes it; never hide it.

Rollback: do not force-push. If release validation fails, keep v4.2.1 unpublished
or delete only the just-created GitHub Release/tag, then revert release commits
with a normal revert. A released APK cannot be replaced silently; publish a new
version/versionCode for fixes. Do not shut down while EAS/GitHub work is active.
